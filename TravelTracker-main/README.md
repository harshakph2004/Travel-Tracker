# Travel Tracker Web Application

A web app to track and visualize visited countries on a world map.

## Tech Stack
- Node.js
- Express.js
- PostgreSQL
- EJS
- HTML, CSS, JavaScript

## Features
- Track visited countries
- Dynamic updates on map
- Database storage using CSV

## Run Locally
1. Clone the repo
2. Run `npm install`
3. Run `node index.js`
4. Open http://localhost:3000
